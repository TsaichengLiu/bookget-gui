# BookGet GUI 使用说明（双栏单窗口版）

## 启动方式
- 双击 `BookGet GUI.app`。
- 全流程在同一个窗口中完成，不会连续弹窗，也不会打开终端。

## 性能与日志机制
- 下载输出不再长期堆在内存：完整任务日志写入临时文件（系统临时目录）。
- UI 日志区只保留最近一段内容用于显示，并自动滚动到最新。
- 为降低卡顿，日志界面采用批量刷新（约每秒一次）。
- 点击 `导出任务日志` 时，把本次任务完整日志导出到保存目录。

## 多网址批量
- 网址输入框支持一次粘贴多个网址（每行一个）。
- 会按顺序逐个执行（第 1 个完成后自动开始第 2 个）。
- 若某个网址中途异常退出，会自动重试 1 次，仍失败则跳过并继续后续网址。
- 任务状态会显示进度编号，例如：`下载中 (1/2)`、`下载中 (2/2)`。
- 进度预扫描基于当前正在处理的网址。
- 多网址模式下会自动使用更稳健的并发设置（默认最多 4 线程，手动设置时最大 8）。

## 支持网站信息
- 顶部按钮：`支持网站信息`。
- 点击后打开可搜索弹窗，显示可点击链接的网站清单。
- 清单来源：[bookget 倉庫 `router/interface.go`](https://github.com/deweizhu/bookget/blob/main/router/interface.go)。
- 另有通用模式：`bookget`、`iiif.io`、`dzicnlib`。

## 历史记录
- 支持恢复上次设置。
- 支持清空最近记录（网址/目录）。
- 当前保留上限：最近网址 8 条、最近目录 8 条。

## 高级参数说明（建议）
- `自动识别模式(app_mode / -a)`：
- `0` 仅按内置支持站点规则下载（默认）。
- `1` 通用批量模式（更像网页资源抓取）。
- `2` IIIF 清单自动识别模式（适合 `manifest.json`）。
- `并发线程(threads / -n)`：
- 同时下载任务数。数值越大不一定越快，且更占内存/CPU。
- 建议 `2-6`；如果卡顿或发热明显，优先降到 `2-4`。
- `抓取间隔(interval / -interval，兼容旧 -speed)`：
- 统一抓取间隔秒数，`0` 为不限速。`bookget-core` 下载流程会在每条 `Get x/y` 后暂停该秒数。
- 网络不稳定、目标站点限流时，建议设 `5-30`。
- `重试次数(retries / -r)`：
- 单个资源失败后的重试次数。常用 `2-5`。
- `页面范围(seq / -seq)`：
- 仅下载部分页，格式如 `4:434`。
- `多册范围(vol / -vol)`：
- 仅下载部分册，格式如 `3:6`。
- `扩展名(ext / -ext)`：
- 输出图片格式，如 `.jpg`、`.png`、`.tif`。
- `PDF 合并(mp / -mp)`：
- 仅特定站点有效；`1` 自动合并、`0` 不合并。
- `书签目录(mark / -mark)`：
- 仅特定站点有效；`1` 仅下载目录页。
- `dezoomify 开关(dzi / -dzi)`：
- IIIF 场景下启用分块拼接下载，常保持开启。
- `dezoomify 参数(rs / -rs)`：
- 高级拼图参数，常用场景建议保持默认。
- `UA(ua / -ua)`：
- 浏览器标识。若站点拦截，可换为常见 Chrome UA。
- `IIIF 图像请求(format / -fmt)`：
- 默认 `full/full/0/default.jpg`，除非站点要求特殊格式，不建议修改。

## 套件结构（已内嵌）
- `BookGet GUI.app` 内已包含 `bookget / dezoomify-rs / config.ini`。
- 只保留 `.app` 也可独立运行。

## 登录/验证码（自动弹窗实验版）
- 若下载站点需要登录或验证码，常见表现是下载结果变成 HTML 提示页（而不是图片/PDF）。
- 本目录内的 `BookGet GUI v1.5 自动登录实验.app` 增加了“失败后自动弹出临时浏览器窗口”的流程：
- 当检测到上述情况，会弹出一个临时登录窗口（内置浏览器），你在里面完成登录/验证码后点击“完成”，窗口会关闭并自动重试下载。
- 登录状态会自动用于本次任务；任务结束后会自动清理临时数据。
- 有些站点在验证通过后会跳转到新的页面（网址会变化）。实验版会自动使用登录窗口里最终停留的“新网址”继续下载，无需手动复制粘贴。
- 另外，在「基础设置」中可勾选 `需登录或验证`：勾选后会在开始下载前先弹出登录窗口（不再等待失败后再弹）。
