# BookGet GUI 帮助

本帮助适用于 `BookGet GUI.app`（本程序是 BookGet 的图形界面封装）。

---

## 1. 这是做什么的？

BookGet GUI 用来批量下载各类数字馆藏/古籍影像资源。你只需要：

- 粘贴网址（可一行一个）
- 选择保存目录
- 点击开始

程序会在后台调用内置的 `bookget` 下载引擎，并把进度、队列状态、实时日志展示出来。

---

## 2. 快速开始（推荐流程）

1. 在「网址」框里粘贴目标链接（一行一个，可一次粘贴多行；也可以点「粘贴」，或把网页链接、`.webloc`、`.txt` 文件拖进框里）。
2. 在「保存到」选择一个文件夹（右侧时钟按钮可选最近用过的目录）。
3. 如果网站需要验证码或登录：勾选「开启弹窗浏览器（需要登录或验证的网站）」。
4. 点击「开始下载」，或按 `⌘↩`。

如果勾选了弹窗浏览器，当程序检测到登录/验证码页面时，会弹出一个临时浏览器窗口：

- 在窗口里完成验证码/登录；窗口上方有后退、前进、刷新按钮
- 如不小心点到其它页面，可在地址栏粘贴正确链接并回车，或点「回到起始页」
- 完成后点「完成」（或「开始下载」），快捷键是 `⌘↩`（单按回车不会误触，方便在登录表单里打字）
- 窗口会关闭，下载继续在后台进行

全部下载结束时，系统会发出通知（第一次会询问是否允许通知）；下载进行中，Dock 图标上会显示还剩几个网址。

---

## 3. 下载内容说明

### 3.1 网址

- 一行一个网址，也可以一行写多个、用空格隔开
- 重复的网址会自动去掉，框下方会显示「已识别 N 个网址」
- 「最近」菜单可以快速填入最近用过的网址；「清空」清空输入框

### 3.2 保存到

- 选择保存目录后，程序会把下载文件写入该目录
- macOS 可能会提示“是否允许访问某文件夹/Downloads”等，这是系统权限提示，属于正常现象

### 3.3 验证：开启弹窗浏览器

勾选后：

- 程序会在需要时弹出临时浏览器窗口，让你完成验证码/登录
- 完成后程序会自动把登录态用于后续下载（不需要你手动复制 Cookie）

不勾选：

- 程序不会自动弹出登录窗口
- 遇到验证码/登录页时，下载通常会失败或只拿到提示页

### 3.4 外观与更多菜单

- 顶部「外观」菜单：切换配色与卡片样式
- 顶部「⋯」菜单：恢复上次设置、清空最近记录、恢复初始设置（把设置、任务队列、进度与日志全部还原，下载进行中不可用）、打开本帮助

## 4. 任务按钮说明

底部只显示当前能用的按钮：

| 状态 | 按钮 | 快捷键 |
|---|---|---|
| 空闲 | 开始下载 | `⌘↩` |
| 下载中 | 暂停、终止 | `⌘P`、`⌘.` |
| 已暂停 | 继续下载、终止 | `⌘P`、`⌘.` |

### 4.1 暂停与继续

- 暂停会结束当前下载进程（包括它启动的所有子进程），并把状态标记为「已暂停」
- 继续时从当前网址接着下载，已经下好的页面会自动跳过，不会整本重下
- 继续会使用界面上当前的设置

### 4.2 终止

终止的语义是“用户主动停止任务”，不是“失败”：

- 当前任务会标记为「已终止」
- 队列中尚未执行的任务也会标记为「已终止」
- 如果当时正在弹出登录/验证窗口，在窗口里点「取消」也会视为终止
- 下载进行中退出 App 会先询问；确认退出会终止下载，已下载的页面保留

## 5. 高级设置（可选）

高级设置用于更精细地控制下载策略。一般用户不需要改动。

打开「高级参数」右侧的开关后才会生效。各项说明（括号里是对应的命令行参数）：

- 识别模式（`-a`）：`0` 内置站点规则（默认）、`1` 通用批量抓取、`2` IIIF manifest 自动识别
- 并发线程（`-n`）：建议 2–6，过大可能导致卡顿或被站点限制
- 失败重试（`-r`）：网络不稳定时可适当增大
- 抓取间隔（`-interval`）：每抓一页后等待的秒数，用于避免被限流
- 页码范围 / 分册范围（`-seq` / `-vol`）：如 `4:50`、`3:6`，仅对部分站点有效
- 输出格式：图片或 PDF 的扩展名
- 浏览器标识（`-ua`）：少数站点需要
- Cookie 文件 / localStorage：高级用户手动指定登录态文件（通常不需要）

## 6. 任务队列、日志与导出

### 6.1 任务队列

队列会显示每个网址的状态（等待 / 下载中 / 重试中 / 已暂停 / 已终止 / 成功 / 失败），顶部是本批的统计。

- 失败的项会直接显示失败原因（如：网络错误、需要登录或验证、不支持的网址），鼠标停留可看完整信息
- 「重试失败项」：把最近一批里失败和被终止的网址重新下载一遍
- 右键单个网址：复制网址、在浏览器中打开、重新下载这一项
- 每次「开始下载」都会新增一批，最多保留最近 30 批；「清空」可清除历史

### 6.2 实时日志

日志会显示下载引擎输出，遇到问题时非常重要。

- 出错的行会标成红色，程序自己的提示行颜色较淡
- 往上滚动查看时不会被新日志强行拉回底部
- 「复制」把当前显示的日志复制到剪贴板；「清屏」只清空显示，导出的日志仍然完整

### 6.3 导出任务日志

在任务结束（或暂停/终止）后，可以点「任务状态」里的「导出日志」：

- 会把本次任务的完整日志导出到保存目录
- 便于你发给维护者排查问题

## 7. 特殊站点：國圖（臺北）rbook.ncl.edu.tw

`rbook.ncl.edu.tw` 的某些入口链接形如：

- `.../NCLSearch/Search/SearchDetail?...`

此类链接对内置下载引擎来说属于“不支持入口”（日志会出现 `Unsupported URL:`）。

为解决此问题，程序内置了 **專用模式**：

- 当检测到 `SearchDetail` 类型链接时，会自动改用 WebView 抓图下载（不再走 a=0/1/2）
- 该专用模式需要勾选「开启弹窗浏览器（适用于需要登录或验证的网站）」才会启用（因为它依赖临时浏览器窗口进行页面加载与抓取）
- 会弹出窗口让你完成验证码/登录
- 点击「开始下载」后窗口隐藏，开始逐页保存 `第X頁.png`
- 图片会保存到：你选择的保存目录下，一个新建的子文件夹 `rbook_...`

如果你发现页面翻页时会短暂黑屏/空白，这是站点的加载方式所致；程序会等待一段时间再抓取。

提示：高级参数里的 `interval` 是统一的“抓取间隔秒数”（兼容旧参数 `speed`）。rbook 会按页间隔抓取；所有 `bookget-core` 下载流程都会在每条页面抓取日志（`Get x/y`）后暂停 `interval` 秒再继续，并且不会自动改写你设置的并发 `n`（例如 `interval=5`）。

## 8. 特殊站点：上海图书馆古籍 gj.library.sh.cn

上海图书馆古籍常见入口链接形如：

- `https://gj.library.sh.cn/org/info/shl?uri=...`

此类链接需要先登录，再进入“查看全文/阅览”页面。程序内置了 GUI 专用适配：

- 检测到上图详情页时，会优先走「开启弹窗浏览器（适用于需要登录或验证的网站）」流程
- 你可在弹窗浏览器里完成登录，并手动点击“查看全文/进入阅览”后再点「完成」
- 程序会自动接管新开阅读窗口，并记录真正的 reader URL
- 如果站点最终跳到 `dhapi.library.sh.cn/pdfview...`，GUI 不再交给 `bookget-core`，而是改走内置的上海图书馆专用 PDF 下载器
- 下载过程中会逐页落盘；如果站点中途限流或返回错误页，保存目录里会留下 `.partial.pdf` 或 `.pages/` 检查点文件

建议：

- 上海图书馆请始终勾选「开启弹窗浏览器（适用于需要登录或验证的网站）」
- 登录后尽量手动点进真正阅览页，再按「完成」，成功率更高

## 9. 常见问题（FAQ）

### 9.1 为什么每次都要我授权保存目录？

这是 macOS 的隐私安全机制：应用需要获得你选择的保存目录写入权限。

它与 Cookie 文件无关；即使不登录，写入下载文件也同样需要权限。

### 9.2 为什么会看到 Cookie 是一个 txt 文件？

下载引擎需要通过 `-c <cookie文件路径>` 读取 Cookie，所以程序会把浏览器里捕获到的登录态暂存成一个临时 Cookie 文件，再交给引擎使用。

- 这个文件一般在 `/tmp`，会自动清理
- 你不需要手动管理，也不需要复制粘贴

### 9.3 “Download complete” 但没有得到书？

有些站点的验证码/登录页也会返回一个很小的 HTML 文件，看起来像“下载完成”，但实际上不是书。

处理方法：

- 勾选「开启弹窗浏览器（适用于需要登录或验证的网站）」，按提示完成登录
- 或者换成站点真正的阅读器/资源链接（例如 `view.do` 或 IIIF `manifest`）

### 9.4 出现 `Unsupported URL`

这表示当前链接不是下载引擎支持的“资源入口链接”。通常需要：

- 找到阅读器入口（例如 `view.do` / IIIF `manifest`）
- 或使用程序对特定站点的“专用模式”（如 rbook）

---

## 10. 隐私与安全说明

- 登录/验证码窗口使用临时浏览器（非持久化存储），关闭后不会保留历史记录
- 程序只在本机使用你完成验证后的登录态，不会上传到任何服务器

---

如需反馈问题，请优先导出任务日志并附上失败网址与操作步骤（是否勾选了“开启弹窗浏览器（适用于需要登录或验证的网站）”等）。
